## Supported Versions

Odigos eBPF-Based Java Instrumentation requires a Java Virtual Machine runtime version of **8** through **25**.

<EbpfKernelVersionNote />

The following JVM runtimes are continuously tested and verified:

| JVM Runtime | Version |
| ----------- | ------- |
| OpenJDK     | 8       |
| OpenJDK     | 11      |
| OpenJDK     | 17      |
| OpenJDK     | 21      |
| OpenJDK     | 25      |
| Azul Zulu   | 8       |
| Azul Zulu   | 11      |
| Azul Zulu   | 17      |
| Azul Zulu   | 21      |
| Azul Zulu   | 25      |

## Instrumentation Libraries

The following packages will be auto instrumented by Odigos:

### HTTP Frameworks

- [`Akka HTTP`](https://doc.akka.io/docs/akka-http/current/) versions `10.0.15 - 10.5.3`. HTTP server and client toolkit for Akka
- [`Grizzly HTTP Server`](https://javaee.github.io/grizzly/) versions `2.3.35 - 4.0.2`. NIO HTTP server framework
- [`http4s Blaze`](https://http4s.org/) version `0.23.18`. HTTP server and client for Scala (Blaze backend)
- [`http4s Ember`](https://http4s.org/) version `0.23.36`. HTTP server and client for Scala (Ember backend)
- [`Jetty (via Dropwizard)`](https://jetty.org/) versions `4.0.14 - 5.0.2`. HTTP server via Dropwizard
- [`Netty HTTP`](https://netty.io/) versions `4.1.121.Final - 4.2.17.Final`. asynchronous event-driven network framework
- [`Spring Boot`](https://spring.io/projects/spring-boot) versions `2.5.15 - 4.1.1`. server side applications framework
- [`Spring Async Server`](https://docs.spring.io/spring-framework/reference/web/webmvc-concurrency.html) versions `3.2.12 - 4.1.1`. asynchronous Spring MVC server support
