Cloud Connectors let Odigos Central discover and instrument workloads in cloud accounts (AWS, GCP, and more) from the same control plane you use for remote Kubernetes clusters and VM hosts.

Each connector manages **one** cloud account boundary (for example an AWS account or a GCP project). From Central you discover workloads in that account, create Sources for the ones you want to observe, and track instrumentation progress.
