## Features

- Instrument [systemd](https://systemd.io/) services and Linux processes
- Automatic OpenTelemetry instrumentation via eBPF with no code changes
- Distributed traces with seamless context propagation
- Collect application logs from instrumented sources (process, Docker, systemd) and export them when a destination accepts the `LOGS` signal
- Continuous CPU profiling (eBPF) with export to other OTLP Profiles backends
