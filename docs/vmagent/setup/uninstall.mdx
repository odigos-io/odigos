<Note>
  Running the agent as a container? See [Docker Deployment](/vmagent/setup/docker#uninstall)
  for how to remove it.
</Note>

To uninstall the Odigos VM Agent, run the following based on your Linux package manager:

<Tabs>
  <Tab title="DNF">
    Using `dnf` (RHEL, Fedora, Rocky Linux):

    ```shell
    sudo dnf remove odigos
    ```
  </Tab>
  <Tab title="APT">
    Using `apt` (Debian, Ubuntu):

    ```shell
    sudo apt remove odigos
    ```
  </Tab>
  <Tab title="RPM">

    If you use a package manager other than `dnf` or `apt`, run the following to uninstall the agent:

    <Note>Replace \<otelcol-version\> and \<agent-version\> with the versions you downloaded.</Note>

    ```shell
    sudo rpm -ev odigos odigos-otelcol
    ```
  </Tab>
</Tabs>

Removing the package leaves configuration and instrumentation data on disk. To fully clean the host:

```shell
sudo rm -rf /var/lib/odigos-agent /var/odigos
sudo rm -rf /etc/systemd/system/odigos-vmagent.service.d
sudo rm -f /etc/polkit-1/rules.d/49-odigos-vmagent.rules
```

The `odigos` user and group are not removed automatically. Remove them only if no other software uses them:

```shell
sudo userdel odigos
sudo groupdel odigos
```
